# 基于FPGA与RK3588的智能车牌识别系统

## 项目简介

本项目面向边缘端智能交通场景，搭建了基于紫光同创PGL50H FPGA与瑞芯微RK3588的FPGA+ARM异构视觉识别系统，实现视频采集、图像增强、网络传输、车牌检测、字符识别和结果显示的完整流程。

## 系统架构

- FPGA：完成OV5640摄像头采集、RGB565像素处理、图像锐化、DDR3缓存、UDP/IP/MAC数据封装和HDMI显示。
- RK3588：通过Python接收FPGA发送的视频数据，完成图像帧重组，并调用YOLOv8和PPOCR模型进行车牌检测与字符识别。
- 通信方式：FPGA通过千兆以太网和UDP协议向RK3588传输图像数据。

## 主要功能

- 720P视频采集
- FPGA实时图像锐化
- DDR3帧缓存
- UDP视频数据传输
- YOLOv8车牌区域检测
- PPOCR字符识别
- HDMI识别结果显示
- 多种光照和车牌类型测试

## 项目指标

- FPGA LUT占用率：17.39%
- FPGA寄存器占用率：11.33%
- FPGA BRAM占用率：16.79%
- YOLOv8 mAP@0.5：0.983
- FPGA输出帧率：约6fps
- 支持蓝牌、绿牌、双层车牌及特殊车牌识别
